# 스티브 억까 시뮬레이터

마인크래프트 자바 26.3용 데이터팩 맵. 거인이 된 플레이어가 엔더 드래곤을 잡으러 가는 스티브를 카드로 방해해서 접게 만드는 게임.

## 플레이

`world` 폴더를 통째로 `.minecraft/saves` 안에 넣고 이름을 `스티브 억까 시뮬레이터`로 바꾸면 돼.

- 카드를 들고 우클릭하면 억까가 들어가. 이름에 ◎ 붙은 카드는 바라보는 곳에 떨어져.
- Shift를 누르고 있으면 확대, 판 주위는 빠르게 돌아다닐 수 있어.
- 7단계: 첫날 → 동굴 → 다이아 → 네더 포탈 → 네더 → 엔더의 눈 → 엔드

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `gen/` | 데이터팩 생성기 (파이썬). `build.py`가 데이터팩을 만들고 모든 명령어를 26.3 명령어 트리로 검사함 |
| `tools/` | 검사 도구. `live*.py`, `bot*.py`는 실제 26.3 서버에 붙어서 테스트함 |
| `tools/ekt/` | 테스트 서버 월드에 넣는 보조 데이터팩 |
| `ref/` | 26.3 명령어 트리, 레지스트리, 블록 목록 |
| `template/` | 월드 기본 파일 (level.dat, 게임 규칙) |
| `world/` | 바로 플레이할 수 있는 월드 |

## 빌드

```
pip install nbtlib pillow
python3 gen/build.py   # out/eokka 에 데이터팩 생성 + 검사
python3 gen/world.py   # world/ 에 월드 패키징
```

서버 테스트는 `server/` 에 26.3 서버(게임 jar + 라이브러리, rcon 켜짐)가 있어야 함. 자세한 건 `gen/world.py` 맨 위 설명 참고.
